# 스티커 기본 삽입 축소 설계

## 요약

스티커 SVG는 원본 크기 정보를 유지해야 하지만, 현재는 원본 크기를 그대로 캔버스에 배치해서 실제 스티커보다 지나치게 크게 보인다. 특히 100mm 기준으로 제작된 SVG는 세로 프레임 폭의 대부분을 차지한다.

이번 변경에서는 원본 `width`/`height`는 그대로 저장하고, 처음 삽입할 때만 기본 배율을 작게 적용한다. 기준은 `100mm` 원본 스티커가 캔버스에서 약 `18mm` 정도로 보이도록 맞춘다.

## 원인

- SVG의 실제 크기를 읽는 것은 맞지만, 그 값을 기본 표시 크기로도 그대로 사용하고 있다.
- 캔버스 좌표계는 실제 인쇄 크기에 대응하므로 100mm 스티커가 매우 크게 보이는 것이 자연스럽다.

## 해결 방식

1. 원본 스티커 크기(`width`, `height`)는 계속 그대로 보존한다.
2. 새 스티커 생성 시 `scaleX`, `scaleY`에 기본 축소 배율을 적용한다.
3. 기본 배율은 "긴 변이 약 18mm로 보이도록" 계산한다.
4. 캔버스 중앙 배치는 축소된 표시 크기를 기준으로 다시 계산한다.

## 기대 결과

- 원본 SVG의 비율과 원본 크기 정보는 유지된다.
- 처음 붙인 스티커는 실제 데코 스티커처럼 작게 시작한다.
- 사용자는 이후 기존처럼 자유롭게 확대/축소/이동할 수 있다.
