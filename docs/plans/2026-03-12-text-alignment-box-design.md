# Text Alignment Box Design

## Summary

오른쪽 사이드바의 텍스트 정렬 버튼은 캔버스 전체가 아니라 현재 선택된 텍스트의 조절 박스 안에서만 좌/가운데/우 정렬을 바꿔야 한다.

## Current Problem

- 현재 정렬 로직은 텍스트 폭을 계산한 뒤 캔버스 전체 너비를 기준으로 `x` 좌표를 재배치한다.
- 그래서 정렬 버튼을 누르면 "문단 정렬"이 아니라 텍스트 객체 전체가 캔버스 안에서 이동한다.
- 선택된 텍스트의 Transformer 박스는 보여 주지만, 정렬 기준이 되는 `boxWidth` 상태는 따로 없다.

## Design

- `CanvasText`에 정렬 기준 폭인 `boxWidth`를 추가한다.
- 새 텍스트를 삽입할 때 `boxWidth`는 현재 텍스트 실측 폭 이상으로 초기화한다.
- 텍스트 렌더링은 `Konva.Text`의 `width`와 `align`을 함께 사용해 박스 내부 정렬로 바꾼다.
- 텍스트 위치 `x`는 박스의 중심점으로 유지하고, 정렬 변경 시에는 `x`를 캔버스 기준으로 다시 계산하지 않는다.
- Transformer 리사이즈가 끝나면 새 박스 폭을 상태에 저장해 이후 정렬 기준으로 재사용한다.

## Expected Result

- 왼쪽 정렬: 선택 박스 왼쪽 안쪽에 글자가 붙는다.
- 가운데 정렬: 선택 박스 중앙에 글자가 온다.
- 오른쪽 정렬: 선택 박스 오른쪽 안쪽에 글자가 붙는다.
- 저장 결과도 화면과 동일한 정렬 상태를 유지한다.
