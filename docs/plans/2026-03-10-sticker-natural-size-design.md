# 스티커 원본 크기 삽입 설계

## 요약

오른쪽 사이드바에서 스티커를 클릭해 캔버스에 추가할 때, 앱이 항상 `100 x 100` 크기로 스티커를 생성하고 있다. 이 때문에 원본이 직사각형인 SVG도 정사각형으로 눌려 보인다.

이번 변경에서는 스티커를 삽입하기 전에 이미지의 실제 크기(`naturalWidth`, `naturalHeight`)를 읽고, 그 값을 새 스티커의 `width`, `height`로 사용한다.

## 원인

- 스티커 삽입 로직이 파일 크기와 상관없이 고정 크기 `100 x 100`을 사용한다.
- 캔버스 렌더링은 저장된 `width`, `height`를 그대로 사용하므로, 삽입 시점의 왜곡이 그대로 보인다.

## 해결 방식

1. 스티커 소스 경로를 받아 실제 이미지 크기를 비동기로 읽는 유틸 함수를 만든다.
2. 새 스티커 생성 전에 해당 유틸을 호출한다.
3. 크기 로드에 성공하면 원본 크기를 사용하고, 실패하면 기존처럼 안전한 기본값으로 넣는다.

## 기대 결과

- `1s_7ss.svg` 같은 직사각형 스티커가 원본 비율과 크기를 유지한 채 캔버스에 추가된다.
- 기존 드래그, 회전, 크기 조절 동작은 그대로 유지된다.
